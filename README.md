## JAVA SPRING FRONTEND ACMUD
Este repositorio contiene todos los trabajos vistos en la clase de Java Spring
El trabajo final esta en la carpeta ProyectoFinal, ya tiene entidades, servicios, repositorios y controladores para un sistema que se conecta a una base de datos y puede ser llamada por diferentes enlaces api
Todos tienen el mismo esquema en la URL para mas facilidad
Por ejemplo la clase Reserva usa:
api/reserva como direccion
* /create-reserva
* /findbyId/{id}
* /deleteById/{id}
* /update-reserva
